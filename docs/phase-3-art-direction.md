# Phase 3 art direction: The measured archive

The project index is conceived as a compact architecture journal. It opens with a calm paper field and a two-part editorial headline, then shifts into a two-column sequence whose image sizes and positions alternate by featured status and record order. The arrangement is data-driven: featured records get the larger composition, while supporting projects use a deliberate mix of portrait and wide frames.

Typography carries the hierarchy. Instrument Serif brings an editorial note to the headline and project names; Geist carries descriptions; Geist Mono is reserved for numbering, controls and technical facts. Thin rules and the existing mineral palette keep the index connected to Phase 2 without adding a new color system.

The filter rail uses native controls and compact labels. Query state lives in the URL so the archive can be shared, refreshed and navigated with browser history. Editorial and ledger views share filters, sorting and pagination. The ledger favors a readable table on large screens and a horizontally scrollable, keyboard-focusable region at narrow widths.

Project previews use a native modal dialog with one dominant image, optional sequence navigation and a restrained facts panel. Remote images retain stable frames, use the existing LQIP field when it contains a data image, and replace failed assets with an identified neutral fallback. Mobile compositions stack the editorial cards, controls wrap into a compact grid, and the ledger remains an intentional table rather than a squeezed card layout.

All copy is provisional. Local seed records are disclosed as demonstration projects; a database failure is identified separately from an unconfigured local fallback.
